# 正确 DST k=10 的五模型配对统计分析技术报告

## 技术摘要

本报告用正确的 GLAM embedding DST-Prototype k=10（`G:\611\glam\proto_embedding_rerun\DST_k_10`）替换上一版误用的 Mammo-CLIP DST 路径，并撤回原训练折间 Wilcoxon 结论。五个模型统一到同一个独立测试集：8,409 张图像、862 名患者，其中 19 名阳性患者；标签冲突、重复 patient-image 键、缺失预测和非有限预测均为 0。

DST k=10 的患者级 AUROC 为 0.8646（95% CI 0.8020–0.9185）。四项预设的配对 DeLong-Holm 比较中，DST 仅显著优于 GLAM（ΔAUROC=+0.1926，95% bootstrap CI +0.0742 至 +0.3277；原始 p=0.0038，Holm p=0.0152）。DST 与 Mammo-FM、Mammo-CLIP、MIL 的差异均未达到显著性。患者级 score-swap permutation 对 AUROC 给出相同的显著性分类。

训练折不需要相同。这里的推断单位和配对单位是共同独立测试患者；没有把不同训练折的指标当成配对重复观测。图像级结果保留患者簇结构，仅作为敏感性分析。

## 数据与指标定义

- DST、GLAM、Mammo-FM、Mammo-CLIP 读取已保存的五折 ensemble 文件。
- MIL 对五个测试预测文件中的同一 patient-image 键取算术均值。
- 所有模型取 patient-image 键交集后得到 8,409 张图像；再按患者对图像概率取均值得到 862 个患者分数。
- 患者标签取患者内图像标签最大值；阳性患者 19 名、阴性患者 843 名。
- AUROC 衡量随机阳性患者的分数高于随机阴性患者的概率；AUPRC 在当前低患病率下补充反映精确率—召回率权衡。

## 统计方法

患者级 AUROC/AUPRC 的 95% CI 来自 20,000 次阳性/阴性患者分层 bootstrap。所有模型在每次迭代中使用完全相同的患者重采样权重，因此 ΔAUROC 和 ΔAUPRC CI 是配对的。DST 对四个 baseline 的相关 ROC 使用双侧配对 DeLong 检验，四个原始 p 值用 Holm 法校正；DeLong-Holm 是主要显著性判据。

考虑到阳性患者只有 19 名，另做 20,000 次患者级配对 score-swap permutation。图像级敏感性分析采用 20,000 次分层患者簇 bootstrap 和 20,000 次患者簇 score-swap permutation，并在图像级 AUROC 和 AUPRC 各自的四项比较内单独做 Holm 校正。所有检验均为双侧，α=0.05，随机种子为 20260728。

## 校验与可重复性

强制断言确认共同图像=8,409、共同患者=862、阳性患者=19、标签冲突=0、重复键=0、预测缺失=0、非有限值=0。正确 DST 在全 8,433 张图像上的患者级 ensemble AUROC 复现为 0.864831，在共同 8,409 张图像上复现为 0.864581。加权 AUC/AP 计算器以 sklearn 小样例核验；DeLong 以已知小样例、sklearn AUROC 一致性和交换模型次序后的对称性核验。最终 Notebook 从头到尾执行成功，独立验证脚本返回 `VALIDATION_OK`。

## 局限性与论文表述边界

最重要的限制是只有 19 名阳性患者，导致置信区间较宽，且小样本下渐近 DeLong 近似可能不稳定；因此报告同时给出配对 bootstrap CI 和 score-swap permutation。共同键限制保证公平配对，但结论只适用于这一共同独立测试队列。分析比较的是已保存模型输出，不支持因果推断，也不证明未显著的模型彼此等效。

## 建议

论文主文使用患者级 AUROC/AUPRC、配对 DeLong-Holm 和配对 bootstrap CI；将 score-swap permutation 和图像级患者簇结果放入补充材料。对 DST 与 Mammo-FM/Mammo-CLIP/MIL 应表述为“未检测到显著差异”，不应写成“性能相同”或“等效”。若后续获得额外独立阳性患者，应优先外部验证并更新置信区间，而不是重新构造训练折来制造形式上的 fold 配对。
